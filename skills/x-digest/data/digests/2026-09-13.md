## 一、Agent 框架与工具

### 1. ChatOllama Agent Runtime 加入渐进式 Skills 加载
- **作者**: @verysmallwoods
- **时间**: 09-12 21:55（北京时间）
- **链接**: https://x.com/verysmallwoods/status/2098772440847397179
- **内容**: 给 ChatOllama Agent Runtime 加上"渐进式 Skills 加载"，参考主流开源 agents（Pi、Codex、DSH）。Runtime 启动时只加载三项元数据——name、description、locator，让模型先知道"有哪些能力可用"，真正匹配到任务时再加载完整 skill，以降低启动开销、按需加载能力。仓库：github.com/sugarforever/chat-ollama。
