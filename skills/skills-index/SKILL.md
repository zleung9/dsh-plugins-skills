# 本机技能索引

1. 读取本目录的 `references/skills-index.csv`，按名称、类别或功能检索；浏览全表时可读 `references/INDEX.md`。
2. `本机状态`只表示文件是否存在。原表的依赖检查结论来自历史记录，不代表当前环境已经验证；插件提供的工具、账号和连接也不会随技能目录链接自动安装。
3. 使用具体技能前，读取其`安装入口`指向的 SKILL.md，并检查当前会话是否具备所需工具。
4. 用户要求刷新时运行 `python3 scripts/refresh_index.py`。脚本扫描 `~/.agents/skills` 的直接子目录，补全新条目，更新文件存在状态，保留缺失记录及历史信息。它只更新本索引，不安装、移动或删除技能。
5. 原始 Excel 保存在 `references/skills-readiness-2026-11-17.xlsx`；CSV 是由它转换并增补生成，没有收到独立的 CSV 附件。
6. 路径按当前用户的 home 生成。原始来源中的 `/Users/zhuliang/` 仅用于保留历史，查找本机资源时改为当前 home。
7. 原技能来源不存在时，明确报告缺失；同名本地技能只可标记为替代版本，不能声称与原版相同。新补入的技能依赖状态标记为未检查。
