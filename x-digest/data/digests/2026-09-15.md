## 一、Agent 框架与工具

### 1. Nex-AGI：一句 Prompt 自动 Blender 建模到 STL
- **作者**: @chasen_liao（转推 @MinLiBuilds）
- **时间**: 09-15 18:19（北京时间）
- **链接**: https://x.com/MinLiBuilds/status/2099805386429915380
- **内容**: 当 Astra 还在让人惊叹"AI 终于会用 Blender"时，Nex-AGI 已直接落地现实。作者只给一句 Prompt——"做一根 6cm 的粉色活动香蕉，省点料"——便基本没再碰 Blender：模型自己用 MCP 建模、用 Computer Use 看结果并自我修正，最后直接吐出 STL 文件，顺手扔进拓竹 3D 打印机。展示了"工具调用 + 视觉反馈 + 自我修正"的完整 agentic 闭环。

### 2. Cline 推出原生桌面应用，脱离 VS Code
- **作者**: @aigclink
- **时间**: 09-15 08:50（北京时间）
- **链接**: https://x.com/aigclink/status/2099662012456522164
- **内容**: Cline 把自己从编辑器里"拆"了出来，发布原生桌面应用，人跟 agent 的对话正成为写代码的主入口。应用不再寄居 VS Code，直接显示 workspace 名称与当前 git 分支，agent 读/改/跑代码全在独立窗口完成；追加消息无需等上一轮干完，后续消息在输入框上方排队，可编辑、重排、立即发或删除。

### 3. MiniCPM5-2B-WebGPU-Pi：浏览器内即开的 Coding Agent
- **作者**: @karminski3
- **时间**: 09-15 06:55（北京时间）
- **链接**: https://x.com/karminski3/status/2099633181934907654
- **内容**: 发现一个思路值得借鉴的 HuggingFace Space 项目 "MiniCPM5-2B-WebGPU-Pi"：不用起 Docker、不用装 Node，打开网页就是一个带虚拟终端、能做文件编辑与 tool_call 的完整 Coding Agent。它用 Pi 包了一个 Coding Agent，再由 MiniCPM5-2B 模型驱动，是端侧小模型 + 浏览器推理做 agent 的轻量范例。
